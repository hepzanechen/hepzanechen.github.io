[X Skills](https://github.com/hepzanechen/x-skills) 是一个公开的 agent 技能与工具集合。它把研究过程中容易被忽略的步骤写成明确的工作方法，供能够读取文档、运行命令的 coding agent 使用。

项目仍处于原型阶段。流程可以帮助组织工作，但流程本身并不能保证结论正确。

## 因果图：留下推理的来路

`causal-graph-research` 将原始证据、事实、推断和因果关系分开记录。图的变更与贝叶斯计算由 Python CLI 执行，让调查过程能够被检查和修正。

它关心的不只是“这个解释合理吗”，也包括“有没有认真寻找其他解释”。在提高因果关系的置信度之前，工作流要求记录证伪检查。

这里的置信度依赖输入证据和建模假设。一个计算出来的数字，不能代替完整的证据搜索。

## 统计思维：先确定要估计什么

新加入的 `statistical-thinking` 从目标总体、样本、观测单位和观测量开始，再确定待估量、研究设计与分析方法。

例如，比较两种方案前，需要先明确：什么算一次独立观测？希望估计的是平均差异，还是某个事件发生概率的差异？多大的差异才值得采取行动？

这些问题决定后续分析的含义。技能还包括不确定性、缺失数据、多重比较、诊断和敏感性分析的检查要点。

## 概念联系与下一步

另外两个技能分别解决学习和行动中的问题：

- `concept-connections`：通过少量有用的对比和类比，说明概念之间的关系与边界。
- `aha-opportunity-scout`：在完成当前任务之后，寻找一个由已有证据支持、成本较低的下一步。

这些技能可以按需要组合。简单问题只需简单流程；更复杂的研究才需要更完整的记录。

## 从哪里看起

从 [仓库 README](https://github.com/hepzanechen/x-skills#readme) 了解结构，再打开 `skills/` 中与当前问题相关的技能。用一个具体任务尝试，检查它是否让问题、证据和结论之间的关系更容易说明。
